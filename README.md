# Audiobook — Wprowadzenie do filozofii umysłu

Józef Bremer. Audiobook przygotowany z dostarczonego PDF, polski głos syntetyczny eSpeak NG. 39 części, łącznie około 17 godzin i 5 minut. Podział techniczny, nie według rozdziałów.

Pliki znajdują się w katalogu [audiobook](audiobook). Odtwarzaj w kolejności numerów. Aby pobrać pojedynczy MP3, otwórz plik i wybierz Download raw file. Całość można pobrać przez Code → Download ZIP.

Synteza może niedokładnie odczytywać przypisy, tabele i obce nazwy.
